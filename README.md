# Родион Мурашкин — сайт-визитка (DevOps / MLOps)

Публичное портфолио: инфраструктура, интеграции, инциденты (STAR), MLOps и статьи.

Этот сайт — **сам по себе пример CI/CD**: статический сайт в репозитории собирается и публикуется через GitHub Actions на GitHub Pages. Открой `.github/workflows/pages.yml` — и это уже демонстрация пайплайна.

## Запуск локально

Без зависимостей и сборки:

```sh
python -m http.server 8000
```

Открой http://localhost:8000. Можно и просто открыть `index.html` в браузере.

## Публикация на GitHub Pages

1. Заведи репозиторий на GitHub (например `BobinRobin/portfolio`) и запушь этот каталог в ветку `main`.
2. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
3. При каждом push в `main` пайплайн `.github/workflows/pages.yml` собирает и публикует сайт.
4. Адрес: `https://BobinRobin.github.io/portfolio/`.

Доменное имя: GitHub Pages поддерживает свой домен бесплатно (HTTPS).

## Структура

```text
portfolio/
├── index.html          # Главная: позиционирование и навигация
├── infrastructure.html # Эволюция платформы, GitOps, безопасность, наблюдаемость
├── integrations.html   # Интеграции: «Честный знак», УПД, ETL
├── incidents.html      # Инциденты по STAR
├── mlops.html          # MLOps: проект, платформа, AI-assisted
├── articles.html       # Статьи и ADR (черновики)
├── assets/             # css + js
└── .github/workflows/pages.yml  # CI/CD для Pages
```

## Правила контента

- Публичный сайт — только обезличенная информация: без внутренних адресов, имён хостов, схем БД, секретов и деталей конфигурации.
- Каждый технический факт подтверждён практикой; MLOps-стек отмечен честно как «основа / PoC», пока не введён в прод-эксплуатацию.

## Миграция

Сейчас это самодостаточный статический сайт (без сборки). При желании можно переехать на Astro или Hugo: контент переносится из markdown-документации, CI/CD-конфиг сохраняется.
