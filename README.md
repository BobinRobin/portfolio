# Portfolio — Rodion Murashkin (v3)

Публичный одностраничный сайт: командная история, суточные метрики, расследования инцидентов, стек, контакты.

## Как устроено
- `index.html` — движок: дизайн, график, встроенный редактор, промпт агента.
- `data.json` — единственный источник текстов и цифр (метрики, кейсы, контакты).
- `.github/workflows/pages.yml` — CI/CD: push в `main` → GitHub Pages.
- `assets/` и остальные `*.html` — предыдущие версии и разделы (новой главной не используются).

## Как править самому (без сборки)
1. Открыть сайт → кнопка «✎ Правки».
2. Текст правится прямо на странице (клик по элементу).
3. Цифры — в панели «Дни» (суточные метрики).
4. «Скачать data.json» → заменить файл в репозитории → commit.
Черновик автосохраняется в браузере (localStorage), пока не экспортирован.

## Ежедневные метрики
Агент обновляет `data.json` по промпту из раздела «Агенту» на сайте:
- источник — bare-metal корпоративный сервер (read-only);
- суточные counts кодов и УПД, длина очередей, p95, ошибки;
- обезличивание; коммит `data: daily metrics YYYY-MM-DD`.

## Голос
Тексты — от «мы» (команда), честная история: ETL-скрипты → перелом в четвёртом → платформа.
Овертаймы — цена роста, не доблесть. Сайт собирается через CI/CD; публичная версия обезличена.
