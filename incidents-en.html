Incident Casebook & Postmortems

Real production investigations — also indexed into our Qdrant vector knowledge base (infra-knowledge) for automated alert enrichment.

Case 1 (INC-040 / 040b). Overseas portal switched UI to Chinese — exporter stalled on 4,000 codes

Symptom. Codes missing production dates jumped from 1,300 to 4,000 (QR_STUCK_NOPD); exports returned db_rows=0 and selector timeouts.

Investigation. The portal silently switched its UI to Chinese locale (CN), breaking English selectors. Later, when it reverted to EN, date filters stayed stuck because the button was labeled Reset instead of Clear / CN.

Fix & Result. Built bilingual selectors (EN/CN), bilingual column mapping (QrCode / Product Date для обеих локалей), and multi-variant filter reset handling. All 4,000 stalled codes were enriched and sent to FTP automatically (resultCode=0).

Case 2 (INC-16 + Distributed Lock). Nightly allocation CronJob failed while concurrent browsers kicked out sessions

Symptom. The nightly delivery-allocation job hit BackoffLimitExceeded, ArgoCD turned Degraded, and overlapping runs with hourly code exports invalidated each other's portal sessions.

Investigation. Three root causes: (1) a truncated password in Vault after manual editing; (2) wait_for_url(until="load") hanging on the corporate SPA; (3) two RPA contours logging into the same account simultaneously.

Fix & Result. Synced credentials in Vault, replaced SPA load waits with URL polling, and deployed a dedicated lock-redis (127.0.0.1:6378) with a cross-process TTL lock (SET key token NX EX 180, 60s heartbeat, atomic Lua release + O_EXCL file fallback). Added kubectl get jobs → Failed detection to devops_alert.py.

Case 3 (INC-17 / 22). Perpetual ArgoCD OutOfSync, phantom K8s worker & logrotate self-kill

Symptom. The marking app stayed OutOfSync in ArgoCD, a K8s utd-worker pod crash-looped on a missing DB column, and logrotate.service failed daily.

Investigation. A legacy base64 Secret in Git clashed with live Vault secrets; the K8s utd-worker was an 8-week-old duplicate of the canonical systemd pipeline; and a *.bak file inside /etc/logrotate.d/ was still executed by logrotate, where pkill -USR1 -f killed the rotation process itself.

Fix & Result. Removed the hardcoded Secret from Git (restoring Synced in ArgoCD), retired the legacy K8s worker manifest, replaced the broken logrotate rule with a systemd archive timer, and added NRestarts > 5 delta alerts.

Case 4 (INC-13 + Network). HashiCorp geoblock & Docker subnet shadowing the corporate proxy

Symptom. terraform init failed on blocked releases.hashicorp.com, while requests to the European proxy corp-proxy:8080 failed with No route to host.

Investigation. HashiCorp blocked provider downloads by region, while a local 172.21.0.0/16 Docker bridge hijacked routing for the entire 172.21.x.x range.

Fix & Result. Removed the conflicting Docker bridge (restoring default gateway routing) and built a local ~/.terraform.d/mirror in ~/.terraformrc — managing all 18 cluster resources via Terraform offline.

Case 5. Shard-local idempotency in TBase & duplicate elimination on retries

Symptom. Default distribution in TBase (distributed PostgreSQL 10) caused cross-shard timeouts when replacing price-monitoring files, while non-unique EAN keys produced duplicates on order retries.

Fix & Result. Re-distributed the table as DISTRIBUTE BY SHARD(file_md5) (making DELETE + INSERT shard-local across 56,697 rows with 0 duplicates) and enforced orderlineno as the idempotency key.
