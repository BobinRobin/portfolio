6 Production Integration Contours

End-to-end data-exchange loops connecting overseas corporate portals, state marking systems, e-invoicing, Telegram feeds, and distributed TBase PostgreSQL.

01 · State Marking

Marking Loop + Bilingual RPA

Orders, stickers, imports, and SSCC aggregation. Strict XML schemas, deterministic 29,999-code chunking, exact response filename matching, and a bilingual selector adapter (EN/CN) resilient to portal locale switches.

02 · E-Invoicing

UPD Intake & Delivery Merge Pipeline

Two-stage intake: logs-only capture → Redis Streams → workers → WAIT_MARKING gate → 30-minute delivery merge window (preserving all item rows and customs declarations) → e-signature trigger → automated sales callback (654,000+ units, 223 signed UPDs).

03 · Allocation & Distributed Lock

Delivery Allocation + Lock-Redis

Nightly Kubernetes CronJob exporting supply allocations (order / inventory / AATP, 22,000+ rows per run). Coordinated via a cross-process TTL lock in a dedicated lock-redis (SET NX EX, 180s TTL, 60s heartbeat, Lua release + O_EXCL fallback) to prevent concurrent browser session clashes.

04 · Retail Intelligence

Competitive Price Monitoring (Telegram → TBase)

Continuous MTProto/Bot API listener + hourly --catch-up ingests Excel reports from groups, filters target sheets, and performs shard-local idempotent replacement in TBase (DISTRIBUTE BY SHARD(file_md5), 56,697 rows across 783 files).

05 · Mail Automation

Mail Forwarder (IMAP → SMTP Poller)

Fault-tolerant Kubernetes Deployment poller: RFC-2047 attachment filename decoding, business-rule filtering (excluding suffix 03), idempotent folder move, offline stdlib-only image build, and freshness gauges in Pushgateway.

06 · Reference GitOps Batch

Sellout Inventory Manager

Reference Python 3.12 pipeline (uv, ruff, mypy --strict, pytest): multi-stage non-root Docker, GitLab CI test → build → gitops, ArgoCD 10-minute CronJob, and DAG scheduler.
