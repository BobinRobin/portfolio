6 интеграционных контуров в продакшене

Сквозные контуры обмена данными между зарубежными корпоративными порталами, государственной системой маркировки, ЭДО, Telegram-источниками и распределённым хранилищем TBase.

01 · Государственная маркировка

Контур «Честный знак» + билингвальный RPA

Заказы (order), нанесение (sticker), импорт (import) и агрегация (SSCC). Жёсткие XML-контракты, чанкинг по 29 999 кодов с сохранением порядка, сверка по точным именам файлов ответа и билингвальный адаптер селекторов (EN/CN) при смене языка зарубежного портала.

02 · Электронный документооборот

Конвейер приёма и слияния УПД

Двухконтурный приём: logs-only фиксация → Redis Streams → воркеры → гейт WAIT_MARKING → 30-минутное окно агрегации по доставкам (с сохранением всех строк <СведТов> и ГТД) → триггер подписания ЭДО → автоматический sales callback (654 000+ единиц, 223 подписанных УПД).

03 · Аллокация и Distributed Lock

Delivery Allocation + Lock-Redis

Ночной Kubernetes CronJob выгрузки распределений поставок (order / inventory / AATP, 22 000+ строк за прогон). Координируется через межпроцессный TTL-замок в выделенном lock-redis (SET NX EX, TTL 180с, heartbeat 60с, Lua-release + O_EXCL fallback), исключая пересечение браузерных сессий одной учётки.

04 · Ритейл-аналитика

Конкурентный прайс-мониторинг (Telegram → TBase)

Постоянный MTProto/Bot API слушатель + часовой --catch-up забирают Excel-отчёты из закрытых групп, фильтруют целевой лист ДетализацияУчастниковРынка и выполняют идемпотентную шард-локальную перезапись в TBase (DISTRIBUTE BY SHARD(file_md5), 56 697 строк из 783 файлов).

05 · Почтовая автоматизация

Mail Forwarder (IMAP → SMTP Poller)

Отказоустойчивый Kubernetes Deployment-poller: декодирование RFC-2047 заголовков вложений, фильтрация по бизнес-правилам (исключение суффикса 03), идемпотентный перенос обработанных писем, офлайн-сборка stdlib-only образа и метрики свежести в Pushgateway.

06 · Эталонный GitOps Batch

Sellout Inventory Manager

Канонический конвейер на Python 3.12 (uv, ruff, mypy --strict, pytest): многоступенчатый non-root Docker, GitLab CI test → build → gitops, ArgoCD CronJob каждые 10 минут и DAG-планировщик.
