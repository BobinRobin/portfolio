MLOps & AIOps in Production

Practical ML infrastructure in action: a live Qdrant vector knowledge base (779 chunks indexed with BAAI/bge-m3), a hybrid self-healing orchestrator, a running MLflow server in K3s, and a reproducible ML pipeline with 88% test coverage.

AIOps & MLOps Architecture

Production RAG · Qdrant

Infrastructure Vector Knowledge Base (779 chunks)

index_rag.py splits all architecture docs, postmortems, runbooks, and skills across all 6 services into semantic sections (up to 900 chars with 100-char overlap), encodes them with BAAI/bge-m3 (1024d, Cosine), and upserts into infra-knowledge. Re-indexed daily via cron at 06:10 MSK; dashboard protected behind nginx basic-auth.

AIOps · Hybrid Orchestrator

Deterministic Autoheal + RAG Context Enrichment

On any alert, rag_context.py (stdlib-only with safe fallback) embeds the symptom via cortex (:6335) and retrieves the top-3 matching incidents and runbooks from Qdrant. Known issues run whitelisted scripts (dry-run → backup → apply → verify); unknown issues deliver RAG-enriched context to eLink.

ML Platform · K3s

MLflow + MinIO + Tested ML Pipeline

mlflow-server, mlflow-db, and MinIO object storage run in K3s. The public repository lesson-08-code-review demonstrates a production-grade ML pipeline: 37 unit tests, 88% coverage, strict reproducibility via uv.lock, flake8/pylint, and mkdocs.
