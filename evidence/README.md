# Evidence: обезличенные скриншоты дашбордов

Сюда добавляются скриншоты Grafana/Prometheus как доказательства к разделу «Инциденты».

## Правила (NDA-безопасность)
- Убирать внутренние адреса, имена хостов, схемы БД и любые цифры, которые можно связать с корпоративными данными.
- Название файла: `INC-<номер>-<кратко>.png` (например, `INC-01-sticker-ftp-skip.png`).
- В скриншоте должна быть видна метрика и временная шкала, а не конфигурация.
