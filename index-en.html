Qdrant Vector Knowledge Base & Hybrid Autoheal Orchestrator

All architecture docs, postmortems, runbooks, and operational skills are indexed into a local Qdrant instance and wired directly into health checks and automated remediation.

  • Knowledge Corpus (`infra-knowledge`, 779 vectors): Markdown section chunking with overlap (`900 / 100` chars), multilingual BAAI/bge-m3 embeddings (1024d) via local cortex (:6335), daily cron re-indexing at 06:10 MSK, UI protected behind nginx basic-auth (:8085/dashboard).
  • Detection & Triage (`devops_alert` + `autoheal`, metrics `:9310`): probes all K8s namespaces, systemd workers, Redis streams, export freshness, and nightly CronJob statuses every 5 minutes.
  • Safe Autoheal Guardrails: known issues trigger deterministic, idempotent runbooks/*.sh along a strict pre-check → dry-run → backup → apply (whitelist) → verify → rollback chain. Unknown anomalies attach top-3 Qdrant RAG chunks and route a short alert to Telegram and full context to corporate eLink.

State Marking & E-Invoicing / UPD Pipeline

Two tightly coupled high-volume loops that directly govern customs clearance speed, shipment release, and revenue recognition.

  • Strict XML Contracts & 29,999-Code Chunking: deterministic splitting of large batches (order, sticker, import, SSCC aggregation) preserving code order so retries remain idempotent.
  • Two-Stage Intake (`logs-only` → Redis Streams → TBase): non-blocking API intake writes raw JSONL and streams events; workers enforce the WAIT_MARKING gate, merge deliveries in a 30-minute window (preserving every item row and customs declaration), and trigger sales recognition after UPD signing.
  • Bilingual RPA Exporter Guard (EN / CN-локаль): when the overseas portal silently switched UI locales between English and Chinese, selectors and date-filter reset buttons (Reset / Clear / CN-Reset) broke. Added bilingual selectors and column mapping (QrCode / Product Date для обеих локалей), unblocking 4,000 codes automatically.

Distributed Locks, Price Monitoring & Mail Relay

Four Kubernetes contours built on a unified engineering template (uv, ruff, mypy --strict, pytest, Helm, ArgoCD, Pushgateway).

  • Cross-Process Distributed Lock (`lock-redis`, `SET NX EX`): two RPA contours shared one overseas portal account and kicked out each other's sessions on overlap. Deployed a dedicated lock-redis (127.0.0.1:6378) with password auth, 180s TTL, 60s background heartbeat, atomic Lua token release, and an O_EXCL file fallback.
  • Competitive Price Monitoring (Telegram → TBase): continuous listener + hourly --catch-up ingests Excel reports from groups (MTProto + Bot API, 3600s session recycling), parses target sheets, and performs shard-local idempotent replacement in TBase (56,697 rows across 783 files).

Platform, Distributed TBase & Infrastructure Hardening

Evolution from ad-hoc scripts to a reproducible platform with strict security and observability standards.

  • Eliminating GitOps Drift & Split-Brain Runtimes: retired legacy K8s worker duplicates that clashed with canonical systemd workers; moved secrets out of Git manifests into HashiCorp Vault (with a 2-minute auto-unseal timer), restoring Synced / Healthy state in ArgoCD.

Selected Investigations (Postmortems)

INC-040 / 040b · Locale Drift

Portal switched UI to Chinese — exporter stalled on 4,000 codes

An unannounced switch of the overseas portal to Chinese (CN) broke English selectors, and switching back to EN left date filters stuck on Reset vs Clear. Built a bilingual selector and column adapter — all 4,000 codes flowed automatically.

INC-16 / Lock · Concurrency

Nightly browser session clashes & SPA login timeout

Two contours sharing one portal account invalidated each other's sessions, while wait_for_url(load) hung on the SPA. Coordinated runs via a distributed TTL lock in lock-redis and URL polling — nightly runs now ingest 22,000+ rows reliably.

INC-17 / 22 · GitOps & Runtime

Perpetual ArgoCD OutOfSync, zombie port :9310 & logrotate self-kill

Moved base64 secrets from Git to Vault (clearing ArgoCD drift), removed a legacy K8s worker duplicate, replaced logrotate pkill -USR1 (which read *.bak and killed itself) with a systemd archive timer, and added NRestarts delta alerts.

INC-13 / Network · IaC & Proxy

HashiCorp geoblock & Docker subnet shadowing the proxy

terraform init failed on HashiCorp regional blocks while a 172.21.0.0/16 Docker bridge hijacked traffic to the European proxy. Built a local filesystem_mirror (18 resources under IaC) and removed the conflicting bridge.
