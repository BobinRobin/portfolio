Selected Investigations (10-Second Scan)

INC-040 / 040b · Locale Drift

Portal switched UI to CN — exporter stalled on 4,000 codes

Built a bilingual selector, column, and filter-reset adapter — all 4,000 stalled codes were enriched and sent to FTP automatically.

Root cause & engineering fix
The portal switched its UI to Chinese locale (CN), breaking English selectors, and on return to EN date filters hung on Reset vs Clear. Added bilingual locators and multi-variant reset handling.
INC-16 / Lock · Concurrency

Nightly browser session clashes & SPA login timeout

Coordinated concurrent RPA contours via a distributed TTL lock in lock-redis and URL polling — nightly runs reliably ingest 22,000+ rows.

Root cause & engineering fix
Two contours sharing one portal account invalidated each other's sessions, while wait_for_url(load) hung on the SPA. Deployed lock-redis (:6378) with SET NX EX 180, 60s heartbeat, and atomic Lua release.
INC-17 / 22 · GitOps & Runtime

Perpetual ArgoCD OutOfSync & logrotate self-kill

Moved secrets from Git to Vault, retired a phantom K8s worker duplicate, and replaced logrotate pkill with a systemd archive timer.

Root cause & engineering fix
A *.bak file in /etc/logrotate.d/ was still executed and killed the process via USR1, while a legacy Secret in Git clashed with Vault. Restored clean Synced state.
INC-13 / Network · IaC & Proxy

HashiCorp geoblock & 172.21.0.0/16 subnet collision

Built a local Terraform provider mirror (18 resources under IaC) and removed the conflicting Docker bridge shadowing the corporate proxy.

Root cause & engineering fix
releases.hashicorp.com blocked downloads by region while a local 172.21.0.0/16 bridge hijacked proxy traffic. Configured filesystem_mirror in ~/.terraformrc.
